# Задачи по доработке фронтенда

У пользоваталей страницы должны отображаться по их роли (роль полльзователя можно получить по ручке /user/role), у некоторых пользователей страницы могут повторяться по сути, но там должен будет отображаться различный функционал
Для администратора следующие:
    1) Мой аккаунт
    2) Страница с логами (с фильтрами, можешь посмотреть какие рализованы на строне бекенда, а остальные сделай на строне фронтенда)
    3) Страница создания новых пользователей (Роли можно получить s.server.GET("/roles", s.rolesList))
        3.1) Роль пользователя должна выбираться из списка
        3.2) Дата рождения выбирается на календаре
        3.3) Добавь валдидация к телефону
    4) Страница с изменением прав пользователей (с возможностью поиска пользоателя s.server.GET("/finduser", s.findUser, роли можно получить s.server.GET("/roles", s.rolesList)))
Для Руководителя:
    1) Мой аккаунт
    2) Страница создания задачи (с возможностью прикрепить к ней материал, но это нужно делать следующим запросом, сначала не бекенд отправляем данные по задаче, а следом отправляем сам материал)
        2.1) Выбор авторов сделай списком как с ролями, вроде как я там реализовавывал возможность поиска пользователя
        2.2) Аналогично для выбора редактора
        2.3) Выбор даты дедлайна сделай как календарь
    3) Страница с задачами
        3.1) Список задач, сделай сортировку  по колонкам статус, дедалйн, приоритет
        3.2) Сделай так что бы перейти в задачу можно было просто кликнув на строку, а не на сама колонку задача
    4) Станица задачи
        4.1) Сделай так что бы отображались файлы прикреплёные к данной задче и их можно было скачать (для получения данных по файлу используй ручку material.GET("/:id", s.materialGet))
        4.2) Увеличь шрифты для названия задачи, описания задачи
        4.3) Убери для руководителя возможно создавать версии задачи
        4.4) Отображай ФИО и почту человека который занимается данной задачей (отдельно был Автор, отдельно данные по редактору)
        4.5) Сделай что бы на версию можно было нажать на всю строчку, а не только на название версии для её открытия
    5) Страница версии
        5.1) Вместо таск id выводи название задачи, вместо айди создателя выводи его ФИО и почту
        5.2) Сделай аналогично что и пункт 4.5 для открытия правок
    6) Страница Правки
        6.1) Сделай вместо всех айдишников данные, у айди версии поменяй на название версии, у айди создателя на ФИО + почту
Для Редактора:
    1) Мой аккаунт
    2) Страница с задачами
    3) Страница задачи (с возможностью создания версии)
    4) Страница версии
    5) Страница Правки
Для Автора:
    1) Мой аккаунт
    2) Страница с задачами
    3) Страница задачи (с возможностью создания версии)
    4) Страница версии
    5) Страница Правки

Поработай с дизайном данных страниц, у ниъ могут быть похожие странциы, но разный функционал учитывай это, особо странциы не плоди, сделай учёт как надо отрисовать ту или иную страницу. Некоторые правки могут подходить разным правам пользователей, а некоторые нет, тоже учитывай данное

Так же для пользователя задач может не быть, в этом случае необходимо выводить
    - Нету актуальных задач
    - версии ещё не созданы
    - Правок нету
Можешь перефразировать данные фразы как хочешь, главное красиво

Дату выводи в формате DD/MM/YYYY, на всех страницах

Убери  (backend: `required:\"true\"`) и тп сообщения, оставь просто их суть но без указания что это относится к бекенду

Сделай кнопку выйти из аккаунта внизу левой штуки

Сделай футтер (либо его аналог, что бы вписалось в текущий дизайн) в котором будет просто написано что это за платформа и будет переход на страницу о проекте (сделай данную страницу), так же что бы была ссылка на гитхаб проекта и на мой аккаунт в телеграмме (@FOMARTEM)

На странице профиля сделай так что бы данные пользователя были не кликабельными

Добавь стилей из старого бустрапа, того самого стиля который был в 2010 для сайтов, хочу что бы он выглядел как платформа для скуфов

Сделай так что бы загузка отображалась не сверху экрана, а на весь экран добовлялось размытие и значок крутящейся загрузки

Некоторые страницы почему то сначала загружаются, а потом становятся просто белыми и на бекенд идёт много запросов, проверь это и исправь тоже
